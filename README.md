# Currency Converter

A simple and modern currency converter web application.

## Features

- Convert between multiple currencies
- Clean and responsive design
- Easy to use interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open `index.html` in your browser
2. Select the currencies you want to convert
3. Enter the amount
4. See the converted result instantly

## Live Demo

You can open the project by running the `index.html` file locally.
